SMC × TradingView

Harga & chart = widget resmi TradingView (real-time). Mesin SMC mengambil candle asli secara otomatis (Binance / Yahoo Finance / Twelve Data), memindai 20 ticker terus-menerus di 1H·15M·5M dan mengikuti ticker TradingView yang sama. Selisih kecil harga dengan TradingView wajar. Tidak ada harga simulasi; Data Guard memblokir rekomendasi jika data tidak valid, cache atau tertunda. Mode SAFE SCALP (default): BUY/SELL hanya muncul saat 1H·15M·5M searah dan tren bersih (tidak fluktuatif), dengan target cepat RR 1:1,5, SL ketat, risiko ≤0,5%. Saat pasar fluktuatif tampil SKIP. BUY?/SELL? = kandidat lolos filter, harga sedang diperbarui (tunggu hingga tanpa tanda tanya).
⚠ Baru 0/20 ticker yang punya data asli. Cara tercepat (±1 menit, gratis): daftar di twelvedata.com → salin API key → klik ⚙ Data → tempel di Twelve Data API key → Simpan. Forex, emas, perak, DXY, ETF & saham terisi otomatis (data disimpan di browser agar hemat kuota 800 kredit/hari). Crypto (BTC/ETH) selalu live lewat Binance. Gunakan tombol Cek sumber data untuk melihat sumber mana yang bekerja di jaringan Anda. Opsional real-time penuh: Worker/GitHub Actions (lihat README).
